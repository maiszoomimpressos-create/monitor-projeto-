# CLAUDE.md

Este projeto usa documentação compartilhada entre modelos de IA. Leia, nesta ordem:

1. `AGENTS.md` — objetivo, estrutura, comandos e regras.
2. `STATUS.md` — estado comprovado atual.
3. `HANDOFF.md` — onde a última sessão parou e próximo passo.
4. `DECISIONS.md` — decisões já tomadas pelo usuário.

Ao concluir cada etapa, atualize `STATUS.md` e `HANDOFF.md`. Nunca registre segredos.
